This project is a personal website following the animecore and webcore aesthetic of early-2000s internet.

Primary colors may include:

- Pastel pink
- Orange red
- Dusty rose
- Salmon color

Images are provided in `src/assets/` to be plastered as much as needed.

Use Windows 95-style cards and include mouse pointer effects, marquee text, and other elements that were prevalent in the oldschool days of the internet.

The `old/` repo is provided for the text content but this project no longer follows that design.
